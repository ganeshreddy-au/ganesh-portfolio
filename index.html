01 Machine learning · Personal project

Credit card fraud detection

End-to-end fraud pipeline on 284,807 real card transactions, where only 492 are fraud. A model that always says "genuine" scores 99.8% accuracy and catches nothing, so this was about finding the rare cases without flooding analysts with false alarms.

284,807transactions
0.17%fraud rate
0.95ROC-AUC
PythonpandasNumPyscikit-learnSMOTESeaborn
Case study +

What I built

  • EDA surfaced the 99.83 / 0.17 split; stratified train/test split kept that ratio in testing.
  • Log-transformed and scaled Amount and Time; SMOTE on the training fold only, so no synthetic rows leaked into evaluation.
  • Compared Logistic Regression, Random Forest and Gradient Boosting on ROC-AUC, precision, recall and F1. Random Forest won and ships as one serialized pipeline.

Next

  • Tune the decision threshold against a cost model and report PR-AUC, which is more honest than ROC-AUC on data this skewed.

Why it's data work
