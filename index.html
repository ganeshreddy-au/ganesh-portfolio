    REF · FRAUD-ML-01 Data ScientistML EngineerData Analyst

    Credit Card Fraud Detection

    An end-to-end fraud detection pipeline built on 284,807 real transactions: the kind of severely imbalanced dataset (99.8% legitimate, 0.2% fraud) that breaks naive models and naive metrics alike.

    Records284,807
    Class split99.8 / 0.2%
    Precision99.8%
    ROC‑AUC0.95
    Recall87%
    F1 score0.86

    Exploratory analysis surfaced the imbalance early, so accuracy was ruled out as a metric before any model was trained. After log-transforming and scaling features and taking a stratified train-test split to avoid leakage, I used SMOTE to rebalance the training data so all three candidate models, logistic regression, random forest, and gradient boosting, could actually learn what fraud looks like rather than just predicting the majority class. Random forest came out ahead on ROC-AUC, precision, recall, and F1 together, and I packaged the trained model and scaler as a serialized pipeline ready for real-time scoring.

    Python · Pandas · NumPy · Scikit-learn · SMOTE · Matplotlib / Seaborn
