# Screenshot comparison checklist

When comparing a rendered screenshot against a reference image, check for
mismatches in:

- Spacing and padding (measure in px)
- Font sizes, weights and line heights
- Colors (exact hex values)
- Alignment and positioning
- Border radii, shadows and effects
- Responsive behavior
- Image and icon sizing and placement

Be specific about what is wrong, with measurements. For example:
"heading is 32px but the reference shows 40px", "gap between cards is 16px but
should be 24px". Avoid vague notes like "spacing looks off".
